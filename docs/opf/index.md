# testr

testr is **AI testing config and proof memory**. It is not a test runner.

- Config: `.testr/product-test-model.json`
- Ledger: `.testr/test-attempts/`
- Sibling: [shipr](https://github.com/eidos-agi/shipr) absorbs `test_commands` as ship proofs

Canonical CLI: Go (`go install github.com/eidos-agi/testr/cmd/testr@latest`).
